# 多模态 AI 与结构化思维课程项目

四人小组协作仓库，用于开发课程项目工作台和整理作业材料。当前包含一个校园活动全周期管控台 Demo，支持从个人项目空间进入单个活动工作台。

## Demo 功能

- 登录后进入“我的项目”，查看、搜索、筛选、创建、复制和归档项目。
- 项目工作台覆盖前期策划、活动筹备、现场执行和活动收尾。
- 提供可编辑、可下载的策划书、宣传材料、执行手册、风险预案和复盘报告底稿。
- 风险清单按可能性和影响程度分级，并提供预防措施、现场响应与升级路径。
- 可按需调用 DeepSeek 起草文案、调用 YosHub 生成宣传图；材料中的未确认事实保留为“待补充”。

## 本地运行

先在仓库根目录创建 `.env`，填入 DeepSeek 和 YosHub API Key（变量名见 [.env.example](.env.example)），然后启动：

```powershell
node workbench/demo/server.mjs
```

打开终端打印的地址，默认是 `http://127.0.0.1:4174/`。服务只监听本机回环地址。API Key 不会发送到浏览器，只有点击相应生成按钮时才会请求对应服务。生成图片保存在 `workbench/demo/generated/`。

## 当前边界

登录是用于演示角色权限的本地身份选择，不是真实账号认证。项目和材料数据保存在当前浏览器，不提供跨设备同步或多人实时协作。该 Demo 是课程项目原型，选题和最终分工以后续小组决定为准。
