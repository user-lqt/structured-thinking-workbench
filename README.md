# 校园活动工作台

**v1.0 正式版** · 多模态 AI 与结构化思维课程项目

面向不同校园活动的全周期管理工作台，把策划、筹备、现场执行和收尾放在同一个项目中。支持个人账号、项目协作、任务交付验收、人员排班与考勤、统一资源台账、风险预案，以及 AI 辅助制作过程材料。

## 主要功能

- **个人与项目空间**：注册登录，创建、打开、复制、归档项目；通过邀请进行编辑协作或只读查看。
- **计划与任务**：活动事实与日程、方案比选、四阶段 WBS、甘特图、检查点、实名责任人和交付版本验收。
- **人员与资源**：加入确认、多人员轮班、冲突校验、个人任务、签到签退、执行报告、物资库存与采购凭证。
- **风险管控**：全流程风险识别、可能性 × 影响评估、分级应急预案、应急处置卡和变更演练。
- **材料与 AI**：DeepSeek 辅助撰写，GPT-image2 生成宣传图；知识库、素材库和卡片工作流统一复用资料，支持 Word、Excel、Markdown、JSON 导出。
- **收尾归档**：材料版本、任务验收、报名考勤、决算与复盘相互关联，形成可检查的项目档案。

## 本地启动

安装 **Node.js 18 或更高版本**后，在仓库根目录双击 `start.bat`，打开 **http://127.0.0.1:4175/**。使用期间保持启动窗口运行；结束时按 Ctrl+C，或双击 `stop.bat`。

项目无需构建或额外安装运行依赖。首次打开先注册或登录；组织者进入项目库，服务人员进入个人任务页。未配置 AI 密钥时，也可以手工编辑、管理项目与导出。

如需 AI，将 [.env.example](.env.example) 复制为根目录 `.env`，私下填写文本和图像服务密钥，再重启服务。图像模型为 `gpt-image-2`。
