# 物料清单

## 何时使用

筹备期要确认「东西齐不齐」。包括「物料清单」「要买什么」「东西准备了吗」。

## 输入

项目信息表 + 任务分解表 + 预算表科目（如有）。

## 输出契约

章节由调用方注入，逐字对齐。全部用 Markdown 表格。

## 各章要求

| 章节 | 列 |
|---|---|
| 一、物料总览 | 分类 / 项数 / 状态（自制 / 采购 / 租借 / 待确认） |
| 二、采购与制作清单 | 序号 / 物料名称 / 规格 / 数量 / 获取方式 / 预算科目 / 责任角色 / 到位时间（D-N） |
| 三、领用与归还登记 | 物料 / 领用人角色 / 领用时间 / 归还时间 / 状态 / 备注 |
| 四、到场清点检查表 | 检查项 / 标准 / 检查人角色 / 结果栏（留空） |

## 物料覆盖要求

按这六类排查，缺项要写明「不涉及」而不是省略：

1. 场地类（桌椅、指示牌、隔离带）
2. 视听类（音响、麦克风、投影、转接线）
3. 宣传类（横幅、海报、易拉宝、纪念品）
4. 办公类（签到表、笔、胶带、工具箱）
5. 保障类（饮用水、医药箱、雨具、照明）
6. 荣誉类（证书、奖杯、奖品）

## 事实边界

- 不得编造供应商、报价、库存
- 数量未知写 `待确认`，不要猜
- 到场清点结果栏一律留空，由现场人员填写

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 六类物料均有交代
- [ ] 采购清单含规格、数量、责任角色与到位时间
- [ ] 未编造供应商与报价
