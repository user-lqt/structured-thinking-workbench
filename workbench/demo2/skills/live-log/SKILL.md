# 现场记录表

## 何时使用

活动当天需要留痕时。记录表是复盘报告的数据来源。

## 输入

项目信息表 + 现场执行手册的 Rundown + 风险台账。

## 输出契约

章节由调用方注入，逐字对齐。全部用 Markdown 表格。

## 各章要求

| 章节 | 内容 |
|---|---|
| 一、记录规则与填写责任 | 记录频次（如每 30 分钟一条）、记录人角色、异常的定义、记录用纸或工具 |
| 二、时段记录表 | 时间 / 环节 / 实际进展 / 与计划的偏差 / 现场人数 / 记录人 |
| 三、异常与处置记录 | 时间 / 异常描述 / 影响 / 处置动作 / 决策人角色 / 是否上报 / 结果 |
| 四、影像素材登记 | 时间 / 拍摄内容 / 拍摄位置 / 拍摄人角色 / 用途（宣传 / 存档 / 复盘） |

## 写作要求

- 时间段划分与执行手册的 Rundown 对齐
- 异常记录要留「是否上报」栏，便于复盘时核查升级链是否生效
- 影像登记要区分用途，方便收尾时快速挑素材
- 每条记录都要有记录人角色，便于追溯

## 事实边界

- 表格内实际数据均为空白待填，不得编造现场情况
- 不得编造拍摄人姓名
- 不得预先填写结果与结论

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 时段与执行手册 Rundown 对齐
- [ ] 异常记录含上报栏
- [ ] 表内数据留空，未编造现场事实
