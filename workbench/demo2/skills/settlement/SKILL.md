# 经费决算表

## 何时使用

活动结束后核账、报销时。应先有预算表。

## 输入

预算表 + 项目信息表（预算上限）+ 任务分解表（采购与物料任务）+ 现场记录中的支出异常。

## 输出契约

章节由调用方注入，逐字对齐。全部用 Markdown 表格。

## 各章要求

| 章节 | 列 |
|---|---|
| 一、决算总览 | 预算总额 / 实际支出 / 结余 / 执行率 |
| 二、分项决算明细 | 科目 / 预算金额 / 实际支出 / 差额 / 凭证编号 / 备注 |
| 三、预算与决算差异分析 | 科目 / 差异金额 / 差异率 / 原因 / 是否需说明 |
| 四、报销与凭证清单 | 序号 / 报销事由 / 金额 / 凭证类型 / 经办人角色 / 状态 |

## 数值要求

- 实际支出未知时，数值列写 `待补充`，**不要用预算数冒充实际数**
- 差异 = 实际 − 预算，超支为正，节约为负
- 执行率 = 实际 / 预算 × 100%，保留整数
- 单项差异率超过 20% 必须在差异分析里给出原因
- 汇总数与明细数必须自洽

## 事实边界

- 不得编造发票号、凭证编号、经办人姓名
- 不得编造支出金额
- 凭证类型只写通用类别（发票 / 收据 / 转账记录）

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 汇总与明细自洽
- [ ] 未知实际支出标为 `待补充`
- [ ] 差异超 20% 的科目有原因说明
