# 宣传文案

## 何时使用

活动需要对外宣传时。包括「写宣传文案」「推文」「群通知」「宣传怎么做」。

## 输入

项目信息表（名称、时间、地点、受众、目标、内容）+ 素材库（已有口号、往届文案）+ 方案比选结论。

## 输出契约

章节由调用方注入，逐字对齐。正文可直接使用的文案写在引用块里，便于复制。

## 各章要求

| 章节 | 必须包含 |
|---|---|
| 一、宣传主题与核心信息 | 一句话主题 + 3 条受众能记住的核心信息（是什么 / 有什么亮点 / 怎么参与） |
| 二、主推文文案 | 标题、导语、正文、参与方式、结尾号召；长度 400–800 字 |
| 三、短文案 | 群通知（120 字内）、朋友圈（60 字内）、广播稿（100 字内）各一条 |
| 四、发布节奏与渠道 | 时间点（D-N）/ 渠道 / 内容形态 / 责任人角色 / 预期触达 |

## 写作要求

- 主题句必须包含活动的差异化亮点，不能是「欢迎大家参加」这类空话
- 时间地点必须逐字来自项目信息表，不得改写或推测
- 节奏至少覆盖 D-14 / D-7 / D-3 / D-1 / D-Day 五个节点中适用的部分
- 文案里出现报名方式时，若报名链接未知，写「报名方式：待确认」，不要编造二维码或链接

## 事实边界

- 不得编造嘉宾、赞助商、奖品、名额、报名链接、报名截止时间
- 不得承诺未确定的福利与规模
- 不得使用「必将」「史上最强」等无法兑现的表述

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 主题句有差异化亮点
- [ ] 三条短文案齐全且在字数上限内
- [ ] 时间地点与项目信息表一致，未编造链接与承诺

## 交付格式

- **主交付**：Word 文档（`.docx`）。章节标题映射为标题样式，Markdown 表格映射为 Word 表格。
- **备选**：Excel（`.xlsx`）与 Markdown（`.md`）。
- **导出入口**：「过程材料」卡片上的 `Word` / `Excel` / `Markdown` 按钮（`Word` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToDocx(doc)` / `materialToXlsx(doc)`。
- **写作要求**：用标准 Markdown 组织正文——`#` / `##` 标题、空行分段、`-` 列表、管道表格；不要写 HTML，导出时只识别这些结构。
