# 海报 / 宣传图

## 何时使用

需要做海报、宣传图、易拉宝、展板时。

## 输入

项目信息表 + 素材库（可选）+ 宣传主题。

## 输出契约

章节由调用方注入，逐字对齐。`一、海报文案` 用 Markdown 列表逐项给出可粘贴的字段。

## 各章要求

| 章节 | 必须包含 |
|---|---|
| 一、海报文案 | 主标题（≤12 字）/ 副标题（≤16 字）/ 标语（≤12 字）/ 时间 / 地点 / 主办，逐项列出 |
| 二、视觉设计说明 | 主色与辅助色（给色值倾向，如深青 + 亮青）、构图方式、字体层级、图形元素、留白要求 |
| 三、尺寸与投放渠道 | 尺寸（如 1080×1440 竖版 / 1920×1080 横版）/ 用途 / 投放位置 / 责任人角色 |

## 写作要求

- 主标题不要写「活动通知」这类通用词，要体现活动名与亮点
- 视觉说明要写成**可执行**的描述（主色深青 #0f7a6c，标题居中，字号占画布 1/10），而不是「要好看大气」
- 至少给竖版与横版两种尺寸，分别说明用途
- 时间地点逐字来自项目信息表

## 事实边界

- 不得编造嘉宾、赞助商、奖品、二维码
- 不得在文案里出现未确认的报名链接
- 无法确定的信息留空，不要用占位符号糊过去

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 文案字段齐全且符合字数上限
- [ ] 视觉说明含色值倾向、构图、字体层级
- [ ] 至少两种尺寸并注明用途
