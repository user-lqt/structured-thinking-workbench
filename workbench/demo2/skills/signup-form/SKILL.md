# 报名表 / 报名页

## 何时使用

活动需要收集报名时。包括「报名表」「报名链接要填什么」「怎么统计报名」。

## 输入

项目信息表（人数、时间、场地、受众）+ 任务分解表（报名相关任务）。

## 输出契约

章节由调用方注入，逐字对齐。字段与统计口径用 Markdown 表格。

## 各章要求

| 章节 | 内容 |
|---|---|
| 一、报名须知 | 报名条件 / 报名时间 / 名额与超额处理 / 取消与变更规则 / 隐私说明 |
| 二、报名表单字段 | 字段名 / 类型 / 是否必填 / 校验规则 / 用途 |
| 三、报名统计口径 | 指标（报名数 / 有效数 / 到场数）、统计时间点、数据来源、责任人角色 |
| 四、截止与确认流程 | 步骤 / 时间点 / 动作 / 通知方式 / 责任人角色 |

## 字段设计要求

- 必填字段尽量少：姓名、联系方式、身份（学生 / 教师 / 校外）三类为底线
- 团队类活动需要：队伍名称、人数、队长、成员名单
- 需要分组或分赛道的，必须有对应的选择字段
- 涉及赛事的必须有「是否已阅读赛制」「是否需要特殊安排」字段
- 收集身份证号、健康信息等敏感字段时，必须写明用途与保管责任人

## 事实边界

- 不得编造报名链接、二维码、报名平台名称
- 名额、截止时间未知写 `待确认`
- 不得承诺「报满即止」这类未确认的规则

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 字段表含类型、必填与校验规则
- [ ] 统计口径覆盖有效报名与到场
- [ ] 未编造链接、平台与名额

## 交付格式

- **主交付**：Excel 工作簿（`.xlsx`）。每个章节一张工作表，表格首行为表头并冻结；纯正文章节按行铺开。
- **备选**：Word（`.docx`）与 Markdown（`.md`），内容与工作簿一致。
- **导出入口**：「过程材料」卡片上的 `Excel` / `Word` / `Markdown` 按钮（`Excel` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToXlsx(doc)` / `materialToDocx(doc)`。
- **写作要求**：每章用 Markdown 管道表格（表头行 + `| --- |` 分隔行 + 数据行），一张表只表达一件事；单元格内不要换行或嵌套列表——导出时按行、按列读取。
