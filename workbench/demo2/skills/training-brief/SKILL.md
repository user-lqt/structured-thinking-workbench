# 志愿者培训提纲

## 何时使用

活动前要给志愿者、工作人员做培训时。

## 输入

项目信息表 + 任务分解表 + 组织分工表 + 排班表 + 风险台账。

## 输出契约

章节由调用方注入，逐字对齐。话术部分用引用块，便于照读。

## 各章要求

| 章节 | 必须包含 |
|---|---|
| 一、培训目标与对象 | 参训岗位、培训后应达到的能力、考核方式 |
| 二、活动概况与当日流程 | 活动目标、时间地点、环节顺序、志愿者到场与离场时间 |
| 三、岗位职责与通用话术 | 每类岗位的职责边界；引导、答疑、拒绝、分流四类话术 |
| 四、应急处理要点 | 常见突发（人员受伤、设备故障、人群拥堵、物品遗失）的首动作与上报对象 |
| 五、培训安排与考核方式 | 时间 / 形式 / 时长 / 材料 / 通过标准 |

## 写作要求

- 岗位职责要写清「做什么」和「不做什么」，边界不清是现场混乱的主因
- 话术必须可直接朗读，例如「同学你好，签到处在右手边，请出示报名信息」
- 应急要点写成「第一步…第二步…」，不要写成原则性表述
- 上报路径要与风险台账里的升级链一致
- 强调志愿者不得自行处理的事件类型（如伤病、纠纷、舆情）

## 事实边界

- 不写具体人名、电话，用角色与分机/频道代替
- 不确定的集合地点、时间写 `待确认`
- 不得编造培训讲师、场地与考核制度

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 含四类可直接朗读的话术
- [ ] 应急要点为分步动作，且上报路径与风险台账一致
- [ ] 未编造人名与电话
