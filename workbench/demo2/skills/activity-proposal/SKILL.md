# 活动策划书

## 何时使用

项目信息表已建立，需要产出可提交、可评审的策划书正文时。包括：

- 「生成策划书」「写一份策划方案」「把信息表扩展成活动方案」
- 「帮我把这次活动写成能交给学院的策划文档」
- 用户上传了学校的 Word 模板，要求「按这个模板写」

## 输入

| 来源 | 用途 |
|---|---|
| 项目信息表 | 名称、类型、日期、时段、地点、人数、预算、主办单位、目标、内容 |
| 任务分解表 | 「组织分工」与「流程」章节 |
| 风险台账 | 「风险与应急预案」章节 |

缺失项直接写「待确认」，**不要停下来追问**。

## 输出契约

```
{
  "title": "活动名称｜活动策划书",
  "sections": [
    { "heading": "一、活动背景与目标", "body": "Markdown 正文" }
  ]
}
```

**输出前先确认四件事：**

1. **章节以调用方注入的模板为准**——逐字照抄其 `heading`，顺序不变，不增删、不合并、不拆分
2. 若调用方未注入模板，使用下面的 8 章默认结构
3. `body` 只写正文，**不要重复写 heading**
4. 全文 1500–3500 字，每章 150–400 字

### 模板优先

调用方可能注入一份来自学校的 Word 模板章节列表。此时：

- **完全以注入的章节为准**，不要套用本文档的默认 8 章
- 模板里的二级条目（形如「（一）活动主题」）也要作为独立 section 输出，不要并进上一章
- 模板若含固定表格（如「申报单位 / 活动名称 / 预计人数 / 经费预算」），在对应章节里用 Markdown 表格还原同样的列
- 模板里有「填写说明」类的括号提示（如「此处填写…不少于 200 字」），按其要求写，但不要把提示原文抄进正文

### 默认结构（仅在未注入模板时使用）

| 序号 | heading（逐字照抄） |
|---|---|
| 一 | `一、活动背景与目标` |
| 二 | `二、活动对象与规模` |
| 三 | `三、活动内容与流程` |
| 四 | `四、时间与场地安排` |
| 五 | `五、组织分工` |
| 六 | `六、预算与经费` |
| 七 | `七、宣传与报名` |
| 八 | `八、风险与应急预案` |

## 章节要求

| 章节 | 必须回答 | 禁止 |
|---|---|---|
| 一、活动背景与目标 | 为什么办；写成**可核验**的目标（如"参与不少于 300 人"） | 空泛口号、无依据的愿景 |
| 二、活动对象与规模 | 面向谁、预计多少人、如何参与 | 编造人数与名单 |
| 三、活动内容与流程 | 有哪些环节、先后顺序、每个环节的动作 | 只写"环节待定" |
| 四、时间与场地安排 | 日期、时段、场地、关键时间节点 | 编造场地与时间 |
| 五、组织分工 | 分组、职责、负责人**角色** | 编造具体人名 |
| 六、预算与经费 | 预算上限、分项科目与占比、控制方式 | 编造金额与报价 |
| 七、宣传与报名 | 渠道、文案方向、报名方式与截止时间 | 编造链接、二维码、主办方 |
| 八、风险与应急预案 | 主要风险、等级、响应动作、升级路径 | 只写"注意安全" |

详细写法与反例见 `references/structure.md`，可照抄的骨架见 `assets/template.md`。

## 写作风格

- 条目化表达，一条一个动作，不要大段抒情
- 用「负责人角色」而不是人名
- 金额写「待确认」而不是估值；人数写「预计 N 人（待确认）」而不是编造
- 不写"本次活动的成功举办具有重要意义"这类无信息量的句子

## 事实边界

- 只能使用输入中已提供的事实
- 缺失的人名、单位、电话、金额、依据一律写 `待确认`
- 不得编造协办单位、赞助商、嘉宾姓名、报名链接、二维码
- 可以给出通用做法（如"设置签到分流"），但不得把这些写成已经确定的事实

- `references/structure.md` —— 八章的逐节写法、字数分配与常见反例

## 验收清单

- [ ] 输出是合法 JSON，顶层只有 `title` 与 `sections`
- [ ] 若注入了模板：`sections` 与模板章节逐字一致、顺序一致、数量一致
- [ ] 若未注入模板：默认 8 章齐全、顺序正确
- [ ] `body` 里没有重复 heading
- [ ] 目标可核验，不是口号
- [ ] 未编造人名、单位、链接、金额
- [ ] 缺失信息已标 `待确认`

## 交付格式

- **主交付**：Word 文档（`.docx`）。章节标题映射为标题样式，Markdown 表格映射为 Word 表格。
- **备选**：Excel（`.xlsx`）与 Markdown（`.md`）。
- **导出入口**：「过程材料」卡片上的 `Word` / `Excel` / `Markdown` 按钮（`Word` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToDocx(doc)` / `materialToXlsx(doc)`。
- **写作要求**：用标准 Markdown 组织正文——`#` / `##` 标题、空行分段、`-` 列表、管道表格；不要写 HTML，导出时只识别这些结构。
