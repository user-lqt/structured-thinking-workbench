# 策划书八章写法

只在需要逐节细化时读取本文件。日常生成遵守 `SKILL.md` 的契约与章节要求即可。

---

## 一、活动背景与目标

**结构**：两句背景 + 三条目标。

背景回答「为什么现在要办」，目标必须是**可核验**的：

| 好 | 差 |
|---|---|
| 参与人数不少于 300 人 | 办一场精彩的活动 |
| 征集作品不少于 60 件，覆盖 8 个学院 | 提高同学们的参与热情 |
| 现场满意度问卷平均不低于 4.0/5.0 | 让大家满意 |

**反例**：「本次活动旨在丰富校园文化生活，提升同学们的综合素质，具有十分重要的意义。」
——三句话零信息量，删掉不影响理解。

---

## 二、活动对象与规模

必须写清三件事：

1. **面向谁**：全校 / 某学院 / 某年级 / 持票观众
2. **规模**：预计人数，注明是「预计」且来源待确认
3. **参与方式**：报名 / 直接到场 / 受邀

人数与场地容量要自洽：预计 300 人就不要配 120 人的场地。若两者矛盾，写出来并标 `待确认`。

---

## 三、活动内容与流程

按时间顺序列出环节，每个环节写清：**做什么、谁负责、多长时间、产出什么**。

```
- 13:30–14:00 签到入场｜签到组｜30 分钟｜产出：签到表与到场人数
- 14:00–14:20 开幕式｜主持组｜20 分钟｜产出：开场视频
```

**禁止**只写「具体环节待定」。若用户确实没给内容，就基于活动类型给出**通用环节建议**，并整段标 `待确认`，而不是留空。

---

## 四、时间与场地安排

- 日期与时段
- 场地名称与容量
- 关键节点表（用相对时间，便于换活动复用）

| 相对时间 | 节点 |
|---|---|
| D-30 | 方案定稿与申报 |
| D-14 | 宣传发布与报名开放 |
| D-7 | 场地与设备确认 |
| D-1 | 彩排与物料到场 |
| D 日 | 执行 |
| D+3 | 复盘与结算 |

---

## 五、组织分工

按**职能分组**，不按人名：

| 组别 | 职责 |
|---|---|
| 策划组 | 方案、流程、审批 |
| 宣传组 | 海报、推文、报名管理 |
| 后勤组 | 场地、设备、物料 |
| 现场组 | 签到、秩序、应急 |

四到六个组为宜。人数少可以合并（如「策划宣传组」）。负责人写角色，人名留 `待确认`。

---

## 六、预算与经费

- 预算上限（数字）
- 分项科目：场地、设备、物料、宣传、奖品、餐饮、应急备用金
- 每项写科目名与「待确认」，**不要编造具体金额**
- 注明控制方式：超支多少需要谁审批

**反例**：列出「场地费 1200 元」而输入里根本没有这个数字。

---

## 七、宣传与报名

| 项 | 内容 |
|---|---|
| 渠道 | 校园公众号、班级群、海报栏、线上报名页 |
| 文案方向 | 一句话卖点 + 时间地点 + 参与方式 |
| 报名方式 | `待确认`（不得编造链接或二维码） |
| 截止时间 | 报名截止、改期通知方式 |
| 物料 | 海报（尺寸待定）、推文、报名表 |

---

## 八、风险与应急预案

引用风险台账，按等级组织：

- **高风险**：列出名称与现场响应动作
- **中风险**：列出名称与预防措施
- **低风险**：一句话带过

必须写出**升级链**与**谁有权暂停活动**。

**反例**：「做好安全保障工作，确保活动顺利进行。」——没有任何可执行动作。

---

## 常见反例汇总

| 反例 | 问题 |
|---|---|
| 「具有十分重要的意义」 | 无信息量 |
| 「环节待定」 | 留空 |
| 「负责人：林同学」 | 编造人名（除非输入里有） |
| 「场地费 1200 元」 | 编造金额 |
| 「扫码报名」 | 编造链接/二维码 |
| 三行写完一章 | 字数不足，未展开 |
