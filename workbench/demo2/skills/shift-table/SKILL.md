# 排班表

## 何时使用

筹备后期要落实每个时段谁在岗。包括「排班」「值班」「谁看场子」。

## 输入

项目信息表（日期、时段、人数）+ 任务分解表 + 组织分工表（岗位）。

## 输出契约

章节由调用方注入，逐字对齐。班次一律用 Markdown 表格。

## 各章要求

| 章节 | 内容 |
|---|---|
| 一、排班总览 | 岗位数 / 班次数 / 覆盖时段 / 总人次 |
| 二、分时段排班表 | 时段 / 岗位 / 人数 / 职责要点 / 交接对象 / 现场位置 |
| 三、岗位交接要求 | 交接时点 / 交接内容清单 / 确认方式（如对讲确认 + 纸质签到） |
| 四、替补与请假机制 | 请假流程 / 提前通知时限 / 替补人选来源 / 空岗应急办法 |

## 排班要求

- 时段划分要覆盖「布置期 — 活动期 — 撤场期」三段，撤场期常被漏掉
- 每个时段必须有明确的现场负责人在岗，不能出现空档
- 单人连续在岗不超过 4 小时，超过要安排轮换
- 关键岗位（总协调、医疗、设备、出入口）必须写明替补
- 时段要写具体时间（`09:00–11:30`），不要只写「上午」

## 事实边界

- 一律写岗位与角色，不写具体人名
- 人数未知写 `待确认`
- 不得编造志愿者姓名、班级与联系方式

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 覆盖布置期、活动期、撤场期
- [ ] 关键岗位均有替补说明
- [ ] 未出现具体人名

## 交付格式

- **主交付**：Excel 工作簿（`.xlsx`）。每个章节一张工作表，表格首行为表头并冻结；纯正文章节按行铺开。
- **备选**：Word（`.docx`）与 Markdown（`.md`），内容与工作簿一致。
- **导出入口**：「过程材料」卡片上的 `Excel` / `Word` / `Markdown` 按钮（`Excel` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToXlsx(doc)` / `materialToDocx(doc)`。
- **写作要求**：默认写成正文段落（空行分段、可用 `-` 列表），只有「本章本身就是一张清单 / 明细 / 登记表」时才用 Markdown 管道表格（表头行 + `| --- |` 分隔行 + 数据行），一张表只表达一件事，单元格内不要换行或嵌套列表。须知、说明、规则、口径、流程、职责这类内容不要塞进表格。导出时表格按行按列读取，正文段落整段铺进工作表。
