# 新闻稿 / 感谢信

## 何时使用

活动结束后对外发布或致谢时。

## 输入

项目信息表 + 现场记录与影像素材清单 + 复盘报告结论 + 参与单位与支持方（如有）。

## 输出契约

章节由调用方注入，逐字对齐。新闻稿用倒金字塔结构。

## 各章要求

| 章节 | 必须包含 |
|---|---|
| 一、新闻稿正文 | 标题（≤20 字）、导语（时间地点主办单位 + 核心事实）、主体（环节与亮点）、结尾（意义与展望）；400–800 字 |
| 二、配图与素材说明 | 建议张数 / 每张的内容 / 拍摄位置 / 图注文字 / 版权与肖像权提示 |
| 三、致合作单位感谢信 | 称谓、感谢事由（具体支持内容）、合作价值、落款 |
| 四、致志愿者与工作人员 | 感谢对象、具体付出、期望与落款 |
| 五、发布渠道与时间 | 渠道 / 发布时间 / 责任角色 / 是否需要审核 |

## 写作要求

- 导语必须回答「何时、何地、何人、何事」，时间地点逐字来自项目信息表
- 用事实与细节代替形容词：写「设置 4 个体验展位」而不是「精彩纷呈」
- 数据（人数、场次、展位数）只能引用已知事实，未知写 `待确认`
- 感谢信要写具体支持内容，不要只写「感谢大力支持」
- 配图说明必须提示肖像权与版权注意事项

## 事实边界

- 不得编造参与人数、嘉宾姓名、媒体报道、赞助金额
- 不得编造领导讲话内容与评价
- 未确认的信息一律 `待确认`

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 导语含时间、地点、主办单位
- [ ] 感谢信写明具体支持内容
- [ ] 未编造人数、嘉宾与媒体信息
