# 活动申报表

## 何时使用

活动需要报批，或用户提到「申报表」「审批表」「立项表」「交给学院的表」。通常在策划书之前完成。

## 输入

项目信息表（名称、类型、日期、时段、地点、人数、预算、主办单位、审批要求、目标、内容）+ 风险台账摘要 + 可选的 `参考样例`（往届申报表 / 学院样表，见下节）。

## 参考样例（有就往死里对齐）

输入里可能带 `参考样例`：用户上传的往届申报表或学院样表。申报表是「格式即合规」的产出，有参考时按下面处理：

- **栏目照抄**：参考的栏目（如「一、活动基本信息 / 二、活动主题和背景 / 三、活动内容和目的 / 四、开展实施 / 五、活动流程 / 六、经费预算」）就是本次章节，逐字一致、顺序一致；由调用方注入的章节标题按注入的写，不要改写、不要合并、不要自创。
- **字段不漏**：参考的字段清单（活动名称 / 活动类别 / 活动时间 / 活动地点 / 活动对象 / 负责人姓名 / 联系方式 / 指导老师姓名 …）每一项都要出现在对应栏目里；一格一行，写不成表格就写「字段：值」。
- **口径照抄**：勾选项（德育 / 智育 / 体育 / 美育 / 劳育）保留选择形式；时间写成 `2026-10-24 9:00—17:00` 这种；金额纯数字；单位照参考。
- **值不照抄**：参考里是别的活动的事实，一律换成当前项目信息表与任务分解表里的事实，缺失写 `待确认`。
- 参考只解析出部分结构（扫描件、图片字段）时，按已解析出的部分对齐，缺的部分用内置章节补齐。
- **原表填值走程序、不走模型**：如果用户在卡片上选了「⇩ 参考表填值」，工作台会把这份参考件直接当成待填的表（离线识别空位），导出时结构逐字节照搬参考、只换填过的值——这条路径不调用本 skill，模型不参与生成，也不得改动结构。模型唯一可能介入的是「AI 补全空位」，契约是只回空位对应的值（{ id, value }），不回结构、不新增栏目、不改标题。

## 输出契约

章节由调用方注入，逐字对齐。每一节用 **Markdown 表格** 承载，不要写成段落。

## 各章写法

| 章节 | 必须包含 |
|---|---|
| 一、活动基本信息 | 活动名称 / 类型 / 日期 / 时段 / 地点 / 预计人数 / 主办单位 / 承办单位，逐行列出 |
| 二、活动内容与流程概要 | 环节名称 + 时间 + 负责人角色；用表格分环节列出 |
| 三、经费预算概要 | 科目 / 金额 / 说明 / 来源；只写预算科目结构，总额与预算上限一致 |
| 四、安全与保障措施 | 风险点 / 措施 / 责任角色；必须包含医疗、疏散、用电三类 |
| 五、审批流转记录 | 审批环节 / 签字栏 / 日期栏，**留空供人工填写** |

## 格式要求

- 审批栏一律留空，写 `（待签）`，不要替谁签字
- 金额写纯数字或 `待确认`，不写约数
- 日期 `YYYY-MM-DD`，时间 `HH:mm`
- 表格列数统一，不要中途增列

## 事实边界

- 只能使用项目信息表中已有的事实
- 承办单位、指导老师、经费来源、审批人未知时一律 `待确认`
- 不得编造盖章单位、文号、编号

## 验收清单

- [ ] 输出是合法 JSON，章节与注入的模板逐字一致
- [ ] 每一节都是 Markdown 表格，列头完整
- [ ] 审批栏保持空白或 `待签`
- [ ] 未编造单位、金额与人名
- [ ] 有 `参考样例` 时：参考的栏目与字段全部出现，标题逐字一致，参考里的项目专属值没有被照抄

## 交付格式

- **主交付**：Excel 工作簿（`.xlsx`）。每个章节一张工作表，表格首行为表头并冻结；纯正文章节按行铺开。
- **备选**：Word（`.docx`）与 Markdown（`.md`），内容与工作簿一致。
- **导出入口**：「过程材料」卡片上的 `Excel` / `Word` / `Markdown` 按钮（`Excel` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToXlsx(doc)` / `materialToDocx(doc)`。
- **写作要求**：每章用 Markdown 管道表格（表头行 + `| --- |` 分隔行 + 数据行），一张表只表达一件事；单元格内不要换行或嵌套列表——导出时按行、按列读取。
