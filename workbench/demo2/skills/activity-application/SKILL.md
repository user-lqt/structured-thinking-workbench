# 活动申报表

## 何时使用

活动需要报批，或用户提到「申报表」「审批表」「立项表」「交给学院的表」。通常在策划书之前完成。

## 输入

项目信息表（名称、类型、日期、时段、地点、人数、预算、主办单位、审批要求、目标、内容）+ 风险台账摘要。

## 输出契约

章节由调用方注入，逐字对齐。每一节用 **Markdown 表格** 承载，不要写成段落。

## 各章写法

| 章节 | 必须包含 |
|---|---|
| 一、活动基本信息 | 活动名称 / 类型 / 日期 / 时段 / 地点 / 预计人数 / 主办单位 / 承办单位，逐行列出 |
| 二、活动内容与流程概要 | 环节名称 + 时间 + 负责人角色；用表格分环节列出 |
| 三、经费预算概要 | 科目 / 金额 / 说明 / 来源；只写预算科目结构，总额与预算上限一致 |
| 四、安全与保障措施 | 风险点 / 措施 / 责任角色；必须包含医疗、疏散、用电三类 |
| 五、审批流转记录 | 审批环节 / 签字栏 / 日期栏，**留空供人工填写** |

## 格式要求

- 审批栏一律留空，写 `（待签）`，不要替谁签字
- 金额写纯数字或 `待确认`，不写约数
- 日期 `YYYY-MM-DD`，时间 `HH:mm`
- 表格列数统一，不要中途增列

## 事实边界

- 只能使用项目信息表中已有的事实
- 承办单位、指导老师、经费来源、审批人未知时一律 `待确认`
- 不得编造盖章单位、文号、编号

## 验收清单

- [ ] 输出是合法 JSON，章节与注入的模板逐字一致
- [ ] 每一节都是 Markdown 表格，列头完整
- [ ] 审批栏保持空白或 `待签`
- [ ] 未编造单位、金额与人名
