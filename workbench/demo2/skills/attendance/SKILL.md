# 签到表

## 何时使用

活动当天需要记录到场情况时。

## 输入

项目信息表（人数、时段）+ 报名表设计 + 排班表。

## 输出契约

章节由调用方注入，逐字对齐。全部用 Markdown 表格。

## 各章要求

| 章节 | 内容 |
|---|---|
| 一、签到说明与统计口径 | 签到方式（纸质 / 扫码 / 两者并行）、有效签到定义、统计时点、责任人角色 |
| 二、观众签到表 | 序号 / 姓名 / 身份 / 单位或班级 / 联系方式 / 签到时间 / 签名 |
| 三、工作人员签到表 | 序号 / 岗位 / 姓名 / 到场时间 / 离场时间 / 签名 |
| 四、签到统计汇总 | 应到 / 实到 / 到场率 / 迟到 / 早退，留空供当天填写 |

## 表格要求

- 观众表预留行数按预计人数给出（如 30 行），并在说明里写明「如不足可续页」
- 表头必须包含单位/班级、联系方式，方便后续核对
- 需要分组的活动（如分赛道、分队伍）增加「组别 / 队伍」列
- 统计汇总表数值栏一律留空，由现场人员填写

## 事实边界

- 不得编造姓名、学号、联系方式
- 到场率、实到人数一律留空
- 不得编造扫码工具与系统名称

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 观众表与工作人员表分开
- [ ] 含统计口径与汇总表
- [ ] 未编造姓名与联系方式
