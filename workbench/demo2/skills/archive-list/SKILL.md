# 资料归档清单

## 何时使用

活动收尾，需要把材料整理留档时。这是全周期的最后一环。

## 输入

项目信息表 + 全部已生成产出清单 + 素材库清单 + 现场记录（影像登记）。

## 输出契约

章节由调用方注入，逐字对齐。全部用 Markdown 表格。

## 各章要求

| 章节 | 内容 |
|---|---|
| 一、归档范围与命名规则 | 归档范围（文档 / 影像 / 数据 / 凭证）；命名规则示例：`活动名-材料名-版本-日期` |
| 二、文档类归档清单 | 序号 / 文档名称 / 版本 / 责任人角色 / 存放位置 / 是否已归档 |
| 三、影像与素材归档清单 | 序号 / 素材名称 / 类型 / 用途 / 版权或肖像权状态 / 存放位置 |
| 四、移交与保管要求 | 移交对象 / 移交方式 / 保管期限 / 访问权限 / 备份要求 |

## 覆盖要求

文档清单必须覆盖工作台可产出的全部材料类型（申报表、策划书、预算、场地方案、分工表、宣传文案、海报、报名、邀请函、物料、排班、培训、风险预案、执行手册、签到、现场记录、复盘、新闻稿、决算），没有的要写「本次不涉及」。

## 事实边界

- 不得编造存放网盘地址、服务器路径、档案编号
- 未确认的移交对象写 `待确认`
- 不得编造版权授权状态

## 验收清单

- [ ] 输出是合法 JSON，章节与注入模板逐字一致
- [ ] 文档清单覆盖全部材料类型，缺项写明不涉及
- [ ] 命名规则给出可套用的示例
- [ ] 未编造路径与档案编号

## 交付格式

- **主交付**：Excel 工作簿（`.xlsx`）。每个章节一张工作表，表格首行为表头并冻结；纯正文章节按行铺开。
- **备选**：Word（`.docx`）与 Markdown（`.md`），内容与工作簿一致。
- **导出入口**：「过程材料」卡片上的 `Excel` / `Word` / `Markdown` 按钮（`Excel` 为主按钮），或页头的「导出材料包（Word）」。程序内对应 `window.WB.exporters.materialToXlsx(doc)` / `materialToDocx(doc)`。
- **写作要求**：每章用 Markdown 管道表格（表头行 + `| --- |` 分隔行 + 数据行），一张表只表达一件事；单元格内不要换行或嵌套列表——导出时按行、按列读取。
