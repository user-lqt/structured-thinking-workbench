# 校园活动工作台 v1.0 正式版

发布整理日期：2026 年 10 月 12 日。功能基线：`d39138e`。

本次确认远端 `main` 与本地功能基线一致，将现有工作台确定为 v1.0 正式版，并补齐使用、维护与课程交付资料。

- 工作台覆盖策划、筹备、执行和收尾，支持账号协作、实名任务、多人排班、资源台账、交付版本和验收。
- 新增图文用户手册、运维指南及 Markdown、TeX 源文件，使用本机 XeLaTeX 编译 PDF。
- 首页更新为当前启动方式与功能，配置示例采用实际图像模型 `gpt-image-2` 和当前服务端口。
- 收录总结报告、汇报 HTML / PDF / 图片型 PPT 及讲稿，便于小组统一使用。

源码路径、浏览器存档键与 `DEMO2_*` 环境变量保留兼容，不进行已有账号和项目数据迁移。正式版通过根目录 `start.bat` 启动，默认地址为 `http://127.0.0.1:4175/`。
